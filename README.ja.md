# kintone Record Diff Viewer

English version: [README.md](./README.md)

同じkintoneアプリ内の2つのレコードを並べて比較し、差分を確認するプラグイン。詳細画面と一覧画面のボタンからレコードを選ぶと、フィールド名・レコードA・レコードBの3列の表がモーダルで開き、差分のある行がハイライトされる。

処理はブラウザ内とkintone REST APIで完結する。外部サーバーへの送信は無く、APIトークンも保持しない。リクエストはすべてログイン中ユーザーのセッションで実行される。

## 機能

- レコード詳細画面に「他のレコードと比較」、一覧画面に「レコードを比較」の起動ボタンを追加する。
- 最大3つの表示用フィールド、またはレコード番号でレコードを検索する。300msのデバウンス付きで、候補は20件まで。
- 差分の種類ごとに行を色分けする。変更ありは黄、Aのみ値ありは赤、Bのみ値ありは緑。一致した行はそのまま表示する。
- リッチテキストフィールドは文字・単語単位のインライン差分を表示する。ASCII英数字の連続は単語、日本語は文字単位で扱う。トークンの一致が10%未満の場合は全体の置き換えとして表示する。
- サブテーブルの行は、行順または指定したキー列で対応付け、追加・削除・変更された行に印を付ける。
- 表示中の差分をMarkdownの表としてクリップボードにコピーする。
- 「差分のみ表示」「システムフィールドを表示」の切り替え状態を、アプリとユーザーごとに記憶する。

## 対応画面と範囲

- 対応: レコード詳細画面とレコード一覧画面（デスクトップブラウザのChrome、Edge、Firefox、Safari）。
- 非対応: モバイル（3列レイアウトがスマートフォンの幅に収まらない）、3レコード以上の比較、アプリをまたぐ比較、過去のリビジョンとの比較。

## フィールドの比較ルール

| フィールド種別 | ルール |
| --- | --- |
| 文字列（1行・複数行）、リンク | 文字列の完全一致。前後の空白も区別する。 |
| リッチテキスト | プレーンテキスト化して比較（マークアップは除去、`<img>` は `[画像]` に変換）。表示はインライン差分。 |
| 数値、計算 | 数値として比較。`1000` と `1000.0` は等しい。空と `0` は異なる。 |
| 日付、時刻、日時 | API値で比較。日時はユーザーのタイムゾーンで表示する。 |
| ラジオボタン、ドロップダウン | 単一値の一致。 |
| チェックボックス、複数選択 | 順序を無視した集合として比較。 |
| ユーザー、組織、グループ | コードで比較。表示名は無視する。 |
| 添付ファイル | ファイル名とサイズだけを多重集合として比較。 |
| ルックアップ | 参照元フィールドのルールに従う。 |
| サブテーブル | 行を対応付けたうえで（行順またはキー）、列ごとに比較。 |

## インストール

1. 依存関係を入れてビルドする。
   ```
   npm install
   npm run build
   ```
2. プラグインをzipにまとめる。
   ```
   npm run pack
   ```
   初回実行時に `private.ppk` が作られ、プラグインIDが表示される。この鍵は非公開のまま保管する（git管理外）。同じ鍵を使い続けると、以後のバージョンが同一プラグインの更新としてアップロードされる。署名済みのzipは `dist/plugin.zip` に出力される。
3. kintoneのシステム設定またはアプリのプラグイン設定で `dist/plugin.zip` をアップロードし、アプリにプラグインを追加する。

## 設定

アプリからプラグインの設定画面を開く。

1. 「検索対象フィールド」で表示用フィールドを1〜3個選ぶ。選べるのは1行テキストとリンクのフィールド（およびそれらを参照元とするルックアップ）だけ。ピッカーが `like` クエリで検索するため。
2. 「サブテーブルの行マッチング」で、サブテーブルごとに行の対応付け方法を選ぶ。行順（初期値）かキー列か。キー列を選ぶと、キー値が同じ行同士が比較される。
3. 保存する。

## ローカルストレージ

表示用の2つのトグルを、`kp-rdv-<host>-<appId>-<userCode>` という形式のキーに `{"diffOnly":true,"showSystem":false}` という値で保存する。中身は表示設定のみ。リセットするには、ブラウザの開発者ツール（Application、Local Storage）で該当キーを消すか、サイトデータを削除する。

## 開発

```
npm install
npm run typecheck   # tsc --noEmit
npm test            # Vitest unit tests for src/core
npm run build       # emits dist/desktop.js and dist/config.js as IIFE bundles
npm run pack        # builds then signs dist/plugin.zip
npm run lint        # ESLint
```

E2Eスペックは `test/e2e` にある（Playwright）。接続先は `KINTONE_BASE_URL`、`KINTONE_USERNAME`、`KINTONE_PASSWORD`、`KINTONE_APP_ID` から読み、未設定の場合は自動的にスキップされる。
